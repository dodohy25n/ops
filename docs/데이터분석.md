# 데이터 분석 결과

> AI Hub 「이상 판별을 위한 금융거래 정보 및 사용자 패턴 합성데이터」 중 카드거래 데이터(Training + Validation 라벨링데이터)를 확인한 결과입니다.

## 1. 기본 규모

| 항목 | 값 |
|---|---|
| 전체 거래 | 1,952,871건 (Training 1,735,885 + Validation 216,986) |
| 이상거래 | 72,008건, 3.69% |
| 기간 | 2021년 1분기 ~ 2024년 4분기 (분기별 CSV 16개) |
| 카드 수 | 2,636장 |
| 가맹점 수 | 9,793곳 |
| 컬럼 수 | 32개 |

제안서에 적은 217만 건은 실제로 약 195만 건이었습니다. 이상거래 비율 3.7%는 실제 값과 같습니다.

## 2. Training과 Validation은 시간으로 나뉘어 있지 않습니다

Validation의 카드 2,577장은 모두 Training에도 있습니다.
기간도 두 파일 모두 2021년부터 2024년까지 같습니다.
따라서 제공된 분할은 같은 기간의 거래를 무작위로 떼어 낸 것입니다.

이 분할을 그대로 쓰면 모델이 미래 거래를 보고 학습하게 됩니다.
그래서 두 파일을 합친 뒤 시간 기준으로 다시 나눕니다.

## 3. 학습에 쓰면 안 되는 컬럼

`이상거래유형`과 `이상거래설명`은 이상거래에만 값이 채워져 있습니다.
이 두 컬럼을 입력으로 넣으면 정답을 미리 보는 셈이므로 반드시 제외합니다.

## 4. 시퀀스를 만들 수 있는가

| 항목 | 값 |
|---|---|
| 카드당 거래 건수 중앙값 | 398건 |
| 하위 10% 카드 | 41건 이하 |
| 거래 20건 미만 카드 | 5.5% |
| 거래 30건 미만 카드 | 7.4% |

대부분의 카드에 거래가 충분히 쌓여 있으므로 카드별 최근 N건 시퀀스를 만들 수 있습니다.
시간 순서는 `승인일자`, `승인시간대`, `승인SEQ` 순으로 정렬하며, 이 세 값과 `카드KEY`가 겹치는 거래는 없었습니다.

## 5. LSTM을 쓰는 근거

**이상거래는 카드 흐름 안에서 몰려서 나옵니다.**
직전 거래가 이상거래였던 경우 이번 거래도 이상거래일 비율은 42.9%였습니다.
직전 거래가 정상이었던 경우에는 2.2%였습니다.
같은 카드의 이전 거래 상태가 다음 거래를 크게 좌우하므로, 거래 한 건만 보는 모델보다 순서를 읽는 모델이 유리합니다.

**가장 많은 유형은 이전 거래와의 비교로 정의됩니다.**

| 유형 | 건수 | 비중 | 데이터의 설명 | 금액 ÷ 직전 10건 평균 (중앙값) |
|---|---|---|---|---|
| 03 카드 위변조 | 32,099 | 44.6% | 최근 거래 패턴에 비해 금액이 급증하고 신규 가맹점에서 결제 | 6.13배 |
| 17 유사수신 | 26,744 | 37.1% | 고매출 가맹점에서 일정 금액 이상 결제 | 1.15배 |
| 09 현금융통 | 11,440 | 15.9% | 매출이 작은 가맹점에서 반복 결제 | 0.95배 |
| 05 허위매출 | 1,725 | 2.4% | 매출 규모가 비정상적인 법인 가맹점 | 0.75배 |
| 정상 거래 | | | | 0.87배 |

유형 03은 정의 자체가 "최근 거래 패턴에 비해"이며, 실제로 직전 10건 평균의 6배가 넘는 금액이었습니다.
이 유형은 이전 거래를 보지 않으면 판단할 수 없습니다.
반면 유형 17, 09, 05는 금액 변화보다 가맹점 특성(매출 규모, 법인 여부)으로 정의됩니다.
그래서 시퀀스의 각 시점에는 금액뿐 아니라 가맹점 정보도 함께 넣어야 합니다.

## 6. 자연스러운 드리프트가 있는가

| 연도 | 거래 | 이상거래 비율 |
|---|---|---|
| 2021 | 506,873 | 3.69% |
| 2022 | 492,726 | 4.12% |
| 2023 | 483,370 | 3.44% |
| 2024 | 469,902 | 3.49% |

이상거래 유형 구성은 4년 동안 거의 같았습니다(유형 03이 43~46%).
따라서 새로운 사기 수법이 등장하는 형태의 드리프트는 데이터에 없으며, 시연에서는 드리프트를 주입해야 합니다.

다만 이상거래 비율은 연도마다 3.44%에서 4.12%까지 달라집니다.
모델이 그대로여도 이상거래 비율이 바뀌면 Precision이 달라지므로, 트리거 기준을 측정으로 정해야 하는 이유를 이 데이터로 보여 줄 수 있습니다.

## 7. 설계에 반영할 점

- 두 파일을 합쳐 시간 기준으로 다시 나눕니다.
- `이상거래유형`, `이상거래설명`은 입력에서 제외합니다.
- 각 시점의 입력에는 금액과 가맹점 특성을 함께 넣습니다.
- 드리프트는 주입으로 시연하고, 발표에서 시뮬레이션이라고 밝힙니다.
- 해외 거래는 전체의 0.8%(16,364건)이고 이상거래 비율은 1.85%로 국내보다 낮습니다. 시연용 신종 사기를 "해외 결제"로 설정하면 학습 데이터에 없던 패턴이라는 설명이 자연스럽습니다.
